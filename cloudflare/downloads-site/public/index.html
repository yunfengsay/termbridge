GOOD TO KNOW

连接之前，
你可能想知道。

电脑和手机需要在同一 Wi-Fi 下吗？+

使用官方 TermBridge Cloud 中继时不需要。电脑与手机客户端分别建立 WSS 出站连接；电脑需要保持开机、联网且 Host 正在运行。你也可以自行部署 Relay。

终端内容会经过中继吗？+

会。WSS 加密传输链路，但目前不是端到端加密，终端内容会在中继中解密和转发。配对码包含连接密钥，请不要公开分享。需要自己管理中继时，可以使用 CLI 的自建 Relay 配置。

如何安装 Mac 客户端？+

{{MACOS_INSTALL_STEP}}旧版名为 TermBridge Control Center，请先退出旧版，安装新版后移走旧 App；连接设置会保留。{{MACOS_INSTALL_SECURITY}}

打开后点击齿轮或按 ⌘, 进入连接设置，可粘贴配对码或点击「导入 TB 命令行配置」。如果 CLI 使用自定义配置位置，点击「选择配置文件」导入对应的 JSON 文件。运行 Agent 的电脑仍需启动 CLI Host。远程直接接入 Herdr 需要 Host 0.1.24 或更新版本。

Android 是正式商店版吗？+

目前提供可直接安装的 Debug 签名测试 APK，适合体验和反馈。按 Android 的提示允许浏览器安装此应用；如果已有不同签名的版本，不要直接卸载，以免丢失数据。

「会话界面」的自动 / 对话 / 终端是什么？+

{{SESSION_UI_PLATFORMS}}它是这台设备上的本机设置，不会同步到其他设备，也不会改变电脑上的 Agent。自动会让可识别的 Codex / Claude 会话开在对话视图，其余开在终端；对话和终端则固定用某一种打开。每个会话内都有切换开关，切换只换这台设备的视图，不会重启或接管 Agent。

对话视图还需要所连接的那台 Host 支持 Agent 对话，也就是真正在跑 Agent 的电脑。{{SESSION_UI_HOST_NOTE}}{{SESSION_UI_WINDOWS_NOTE}}Host 不支持时，对话视图会说明原因并回到终端，终端本身不受影响。附件、停止和审批一律在终端操作。

关闭客户端，会结束 Agent 吗？+

断开终端连接不会销毁已有 Herdr 会话。CLI 终端连接中，Ctrl+C 发给远端任务；Ctrl+] 打开断开提示，再按 D 退出当前连接。Host 服务与终端客户端分别管理。
