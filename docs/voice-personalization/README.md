## 本地阅读

直接用浏览器打开 `index.html`。页面不需要 CDN、网络字体、账号或麦克风权限；学习演示仅使用内置合成数字，刷新即清除。没有统计上报或本地持久化。

```sh
node docs/voice-personalization/check.mjs
```

上述命令只校验本目录的文章资源、链接、学习演示与设计约束，不测试真实 DDSD。网页布局验证的重跑方式见 [validation.md](validation.md)。
