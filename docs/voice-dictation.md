# 语音输入与实时通话

通话内另外提供 [静音执行](voice-silent-call.md)：继续说话，AI 使用高级模型但只显示文字与工具进度。它与本文的输入框口述并存，不能互相替代。

麦克风入口是“帮我输入”，电话入口是“跟我通话”。二者共用 Global 历史、附件、工具、Agent 名单；模型选择独立放在设置的“执行模型”，思考维持关闭。

## 语音输入

`ComposerDictation` 管录音和 ASR 生命周期，`DictationDraft` 管片段合并与发送词，`DictationLevelView` 显示紧凑音量条。输入区使用可编辑文本，不显示通话圆球。

```text
点击麦克风 → 授权/加载 → 本地 VAD → 百炼 ASR → 输入框（临时转写 → 最终片段）
停顿 → 只结束 ASR 片段，继续输入
点击发送 / 最终片段末尾的发送词 → 停录音 → 等待 ASR 收尾 → brain_send → 文字/工具/Agent
停止输入 → 收尾后保留草稿，不发送
手动改字 / 离开前台 / 断网 → 取消录音，保留可见草稿，不自动发送或重开
```

- 复用 `OnDeviceVoiceCapture`、本地 VAD 和标准音频路由，不注册后台麦克风或悬浮服务；不是用 Omni 通话关闭音量。
- 复用 `brain_transcribe_*`，自定义发送词与技术词作为 ASR hints。句末识别完成不等于发送；临时识别中的发送词不会触发任务。
- 手动改字会停止口述，迟到的 ASR 不能覆盖用户编辑。可以再点击麦克风接着输入。
- 每次录音最多 50 秒，自动收尾保留草稿；收尾最多等 8 秒，超时不自动提交未确认文字。
- 当前编排进行时可以继续编辑/口述草稿，发送按钮等待当前请求结束；已派发 Worker 可继续后台执行，此时仍可发送后续指令。已有停止编排按钮保留。
- 普通文字与口述提交均用已有高级文字路由，3.8 思考关闭；回复不启动 TTS。实时通话保留独立入口。
- 不在失败后自动切入通话，不自动恢复麦克风。前台录音复用防息屏设置，退后台停止录音，不阻碍已派发任务继续。

## 兼容与验证

Host 必须声明 dictation 能力；手机、Host 需一起更新。本轮同步 Android/iOS 协议字段，新增 UI 为 Android。`DictationDraftTest` 验证分段、重复临时转写、明确发送词；Node 验证 ASR text-only 模式、技术词和 finished 回执。真实手机长句、口音和暂停后的转写精度仍需要交互验收。
